# 「막차」 씬·비트 플랜 (scene-orchestrator 산출물)

> 본 문서는 TinyWorld식 다중에이전트 환경을 **모사**한 설계도입니다. 실제 시뮬레이션 실행 로그가 아니라, 내러티브-신서시스트가 산문으로 렌더링할 **의도된 환경·상황·비트**를 규정합니다. 서술 순서와 감정 곡선은 리드가 조정 가능하도록 열어 둡니다.

---

## 1. 설정 (Setting)

**무대:** 겨울 자정, 익명의 대도시. 143번 시내버스, 하행 종점행 막차. 실제 운행이 아니라 "오늘이 이 노선의 마지막 밤"이라는 사실이 공기에 깔려 있음(승객은 대부분 모름 → 후반 개시).

**환경 디테일**
- **온도/계절:** 바깥 영하. 히터가 과하게 돌아 유리마다 성에·김서림. 손가락으로 글씨 쓸 수 있는 상태(활자 애착 인물의 소도구로 활용).
- **조도:** 형광등 두 줄 중 한 줄이 미세하게 깜빡임. 창밖은 가로등·편의점 간판·신호등의 붉고 푸른 번짐. 실내는 창백하게 밝고 바깥은 검음 → 버스가 하나의 '떠 있는 방'처럼 느껴짐.
- **소리:** 엔진 저음, 정차 벨의 단음, 안내방송("이번 정류장은…"), 하차문 공압음, 소율의 이어폰에서 새는 얇은 고음, 히터 송풍. 승객 수가 적어 침묵이 크게 들림.
- **냄새/촉감(암시):** 젖은 외투, 히터의 마른 먼지 냄새, 배기석에게서 옅게 남은 목욕탕 소독약·비누 냄새(직업의 잔향).

**좌석 배치 (broadcast 반경 설계)**
```
        [운전석: 오만수]  ← 룸미러로 뒷좘 관찰
   ┌──────────────────────────────┐
   │ 앞문                          뒷문 │
   │                                    │
   │  (좌)윤정민 ── 통로 ── 배기석(우)  │  ← 중앙부, 통로 마주보는 대각
   │                                    │
   │          한소율 (뒤쪽 창가, 좌)   │  ← 두 사람보다 두어 줄 뒤, 반쯤 고립
   └──────────────────────────────┘
```
- **윤정민:** 중앙 좌측, 창가. 무릎에 문고본. 대리 콜 대기 지점까지 이동 중이라 휴대폰을 자주 확인(시간 압박의 신체화).
- **배기석:** 중앙 우측, 통로 쪽. 정민과 대각. 말을 걸기 가장 쉬운 물리적 위치 = **대화 촉매의 자리**.
- **한소율:** 뒤쪽 창가. 이어폰·후드로 방어막. 손엔 폐기 삼각김밥 봉지. 물리적으로 떨어져 있어 '엿듣다가 끌려들어오는' 구조 성립.
- **오만수:** 운전석. 대화에 거의 참여 안 함. 룸미러·백미러로 세 사람을 프레이밍하는 **관찰자/최종 발화자**. 마지막 운행이라는 정보의 유일한 보유자.

## 2. 자극 / 상황 (Stimulus)

**초기 사건(개시 트리거):** 버스가 급정거한다(도로에 뛰어든 고양이 혹은 무단횡단자 — 위험 아닌 놀람 수준). 그 반동에 **정민의 무릎 위 문고본이 통로로 떨어져 배기석 발치까지 미끄러진다.** 배기석이 허리 숙여 책을 주워 건네며 표지를 흘끗 본다.

- 배기석의 첫 발화(수다 기질 발동): "이 시간에 책을 다 보고. 요즘 이런 거 읽는 사람 없는데." → 정민의 최소 응답("…감사합니다").
- 급정거로 소율의 이어폰 한쪽이 빠지고, 삼각김밥이 흔들려 그녀도 잠깐 고개를 든다 → **세 승객이 동시에 같은 순간을 공유**(broadcast 0: 물리 사건이 전원에게 도달).

이 트리거는 (a)물리적 접촉(책), (b)배기석의 외향성, (c)소율의 우발적 편입, 세 요소를 한 번에 점화한다.

---

## 3. 비트 플랜 (Ordered Beats — broadcast → run 리듬)

각 비트 = 한 '스텝'. **[참여자] / 전진하는 긴장 / 새로 드러나는 정보·감정** 순.

**BEAT 1 — 개시: 떨어진 책**
- [배기석 → 정민 / (소율·오만수 관측)]
- 긴장: 침묵 vs. 접촉. 배기석이 말을 트고 정민은 방어적으로 짧게 응한다.
- 드러남: 정민이 '활자에 기대는 사람'임이 행동으로 노출. 배기석은 누군가와 말하고 싶어 안달임(집에 가기 싫은 자의 지연 행동)이 은근히 배어남.

**BEAT 2 — 배기석의 과잉 공개**
- [배기석 → 전체 / 정민 반응]
- 긴장: 배기석의 수다가 공기를 채우자 정민의 불편·소율의 무시가 동시에 발생.
- 드러남: 배기석이 "오늘 40년 하던 목욕탕 문 닫고 열쇠 반납했다"를 **가볍게, 농담처럼** 흘림. 무게를 스스로 눌러 감추는 방식 → 관객은 진짜 상실을 감지하지만 인물들은 아직 흘려듣는다.

**BEAT 3 — 소율의 우발적 편입**
- [소율 ↔ 배기석 / 정민 관측]
- 긴장: 소율이 참지 못하고 반쯤 비꼬듯 끼어든다("그럼 이제 뭐 하세요") — 방어적 태도가 역설적으로 대화를 연다.
- 드러남: 소율의 손 안 폐기 삼각김밥, 편의점 야간 알바 후 귀가라는 정황이 노출. 재수생이라는 사실은 아직 숨김(가시만 세움).

**BEAT 4 — 오해/마찰의 작은 스파크**
- [정민 ↔ 소율 / 배기석 완충]
- 긴장: 정민이 무심코 한 말("젊을 때가 좋지")이 소율의 예민한 지점을 건드려 날이 선 응수가 돌아온다. 첫 실질 갈등.
- 드러남: 정민이 서점 계약직+대리기사 투잡이며 지금 콜 대기 지점으로 가는 중임을 방어적으로 흘림 → '나도 안 편하다'는 항변. 배기석이 특유의 넉살로 분위기를 눅인다.

**BEAT 5 — 균열에서 스며나오는 진심 (정민)**
- [정민 → 소율·배기석]
- 긴장: 방어를 낮추는 첫 인물. 시간 압박(콜 대기)과 딸 이야기가 겹치며 목소리가 흔들린다.
- 드러남: 별거 중, 다섯 살 딸. "책 읽어주다 잠드는 걸 못 본 지 오래됐다" 류의 구체 디테일. 문고본의 의미가 여기서 재정의됨(딸에게 읽어주려던 책, 혹은 자신을 지탱하는 활자).

**BEAT 6 — 소율의 해빙**
- [소율 → 전체]
- 긴장: 남의 솔직함이 자기 방어를 무장 해제. 이어폰을 마저 뺀다(물리적 신호).
- 드러남: 재수생. 오늘 성적/모의고사 혹은 지원 관련 무언가가 어긋난 밤이라는 암시. 폐기 삼각김밥 = 하루의 끝을 때우는 저녁 → '끝' 모티프가 세 인물에게 공명하기 시작.

**BEAT 7 — 공명: 세 개의 '끝'이 겹친다**
- [배기석 ↔ 정민 ↔ 소율]
- 긴장: 갈등이 연대로 전환. 서로의 상실을 정면으로 위로하지 않고, 사소한 실용적 다정(삼각김밥 나눠 먹기, 책 제목 알려주기, 배기석이 목욕탕 단골 이야기로 웃음 주기)으로 표현. **감상주의 억제 지점 — 위로의 말 대신 행동/유머.**
- 드러남: 배기석의 아내 사별이 여기서 처음, 아주 짧게, 목욕탕 이야기 끝자락에 딸려 나온다("집사람이 카운터를 봤었는데"). 그의 수다가 실은 빈집을 미루는 소리였음이 확정된다.

**BEAT 8 — 종점의 압력 / 오만수의 개입**
- [오만수 → 전체]
- 긴장: 안내방송 "이번 노선은 오늘로 운행을 마칩니다" 혹은 종점 도착 임박. 시간이 강제로 대화를 끊는다.
- 드러남: 22년차 기사 오만수가 이 143번의 **마지막 운행**임을 처음이자 마지막으로 발화(과묵한 관찰자의 한마디). 네 번째 '끝'이 밝혀지며, 이 방(버스) 자체가 사라질 공간이었음이 드러난다. 관찰자였던 그가 실은 가장 큰 종결을 안고 운전하고 있었음.

**BEAT 9 — 하차, 각자의 방향 (종결 비트)**
- [전체 → 분산]
- 긴장: 해소가 아닌 '조금 나아진 채로 흩어짐'. 연락처를 교환하지 않는다(감상 억제).
- 드러남: 각자 다른 정류장에 내린다. 소율이 먼저(집), 정민이 콜 대기 지점, 배기석은 종점까지. 마지막 프레임 = 텅 빈 버스에 남은 배기석과 오만수, 혹은 성에 낀 창에 누군가 손가락으로 남긴 글자 한 자. 히터 소리와 종점의 정적.

## 4. 환경 제약 (Constraints — 서사를 조이는 장치)

- **막차·종점 데드라인:** 대화의 총량은 '종점 도착'까지로 물리적으로 한정. 모든 고백은 이 시간 안에 일어나야 함 → 압축된 친밀감의 알리바이.
- **하차 타이밍의 시차:** 세 승객의 목적지가 달라 순차 하차. 누가 언제 내리느냐가 각 인물의 서사 분량과 퇴장 순서를 규정(소율 → 정민 → 배기석).
- **정민의 이중 시간 압박:** 대리 콜은 언제 울릴지 모름. 휴대폰 진동이 대화를 끊거나 서두르게 하는 내적 타이머로 작동. 콜이 울리면 그가 강제 퇴장.
- **폐선이라는 숨은 시한:** 오만수만 아는 정보. BEAT 8까지 유보되어 반전 겸 주제 통합 장치로 기능. 이후 상황을 되돌릴 수 없게 만든다.
- **좌석 물리 거리:** 소율은 떨어져 앉아 있어, 대화 편입에 '한 번의 계기'가 반드시 필요(급정거로 해결). 편입 후에도 이동해 앉을지(근접) 그대로일지(거리 유지)가 친밀도의 척도.
- **저온·과열 히터의 대비:** 바깥의 추위 = 각자가 돌아갈 현실. 버스 안의 과한 온기 = 일시적·인공적 유대. 하차 = 다시 추위로 나감. 환경이 곧 은유.
- **비참여 원칙(오만수):** 오만수는 BEAT 8 이전까지 발화 금지(관찰만). 이 침묵의 제약이 그의 한마디에 무게를 싣는다.

## 5. 감정 곡선 (arc) — 리드용 한 줄 요약

경계와 방어(냉기) → 우발적 접촉과 마찰(불꽃) → 각자의 '끝'을 하나씩 꺼내며 스며드는 이해(온기) → 폐선이라는 네 번째 끝의 폭로로 정점(먹먹함) → 위로 대신 담백한 다정을 남기고 각자의 추위로 흩어지는, **조금 덜 외로워진 이별**.
