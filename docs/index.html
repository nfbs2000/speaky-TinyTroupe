TinyTroupe

구체적인 persona와 환경을 설계하고, 상호작용을 실행하고, 그 결과를 분석하는 실험 도구입니다. 답을 대신 내는 assistant가 아니라 사람을 이해하기 위한 simulator라는 경계를 먼저 배웁니다.

CORE MODEL

사람, 환경, 서사를 분리해 설계합니다

각 추상화가 무엇을 소유하는지 알면 시뮬레이션 결과와 실제 관찰을 혼동하지 않고 글쓰기 재료로 사용할 수 있습니다.

01

TinyPerson

배경, 성향, 목표, 말투와 선호를 가진 가상 인물입니다.

02

TinyWorld

여러 persona가 자극을 받고 단계적으로 상호작용하는 실험 환경입니다.

03

TinyStory

관찰된 상호작용 trace를 명시적인 목적에 맞는 서사로 연결합니다.

04

Experiment Loop

설계, 실행, 분석, 수정의 반복을 통해 질문과 시뮬레이션을 다듬습니다.

WRITING WITH SIMULATION

어떤 글을 만들 수 있나

TinyTroupe 원전과 예제가 보여주는 패턴을 글쓰기 과정으로 번역할 수 있습니다. 시뮬레이션 반응은 실제 인간 조사 결과가 아닙니다.

Persona 대화극

서로 다른 배경과 목표를 가진 인물의 목소리를 설계합니다.

장면 기반 단편

TinyWorld식 환경과 단계별 자극을 장면과 갈등의 뼈대로 사용합니다.

모의 인터뷰

특정 독자나 사용자의 관점을 탐색하되 simulated임을 명시합니다.

초안 비평

가상 독자 반응과 일관성 검사를 분리해 수정 근거를 만듭니다.

교육 시나리오

목적이 분명한 상황을 설계하고 다양한 선택과 반응을 비교합니다.

팀 제작 글

Claude 리드가 실제 child 결과를 수집해 하나의 원고로 종합합니다.

OBSERVED CLAUDE RUN

정의만 한 팀이 아니라, 실제로 실행한 팀을 공개합니다

Education Shell의 Claude가 TinyTroupe 원전을 읽고 역할을 설계했습니다. 이어지는 새 세션에서 다섯 child agent를 실제 실행해 캐릭터, 장면, 초안, 독자 반응과 편집 노트를 만들고 리드가 최종 글을 종합했습니다.
