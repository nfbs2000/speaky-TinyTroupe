TINY TROUPE PUBLIC LEARNING

TinyTroupe를 소스와 Claude 팀 산출물로 읽습니다

이 저장소는 Microsoft TinyTroupe 원전의 한국어 소스 가이드와, 그 방법론을 Claude 스킬·에이전트·팀 런·워크플로 런으로 재현한 공개 산출물을 분리해서 보여준다.

한국어 소스 가이드 TinyPerson, TinyWorld, memory, extraction, validation을 upstream source 기준으로 읽는 mdBook. Claude 팀·스킬·런 .claude 폴더의 팀 정의, 스킬, 에이전트, workflow, team-runs 원문과 확인 코멘트. Claude 워크플로·런 .claude/workflows의 동적 workflow 스크립트와 workflow run 기록, 결함 분석, 반복 실행 목록.
