팀이 찾은 절차를 코드가 반복하게 만든다

워크플로는 에이전트 목록이 아니다. 입력을 검사하고, 어떤 역할을 언제 실행하며, 무엇을 다음 단계의 증거로 넘기고, 어디서 실패시킬지를 코드로 고정한 실행 계약이다. 이 페이지는 실제 포커스 그룹 런의 성공과 결함을 함께 보여준다.

THE CORE LESSON

자동화는 판단을 없애는 일이 아니라, 이미 검증한 판단을 반복하는 일이다

절차가 아직 흔들리는데 워크플로부터 만들면 오류도 빠르게 반복된다. 먼저 팀 런에서 역할과 품질 기준을 부딪쳐 보고, 입력·출력·실패 조건이 고정된 부분만 코드로 옮긴다. 실행 기록에서 결함을 찾으면 다시 스킬과 워크플로를 수정한다.

TWO WORKFLOWS

현재 코드에 고정된 두 실행 경로

둘 다 JSON 문자열 입력을 다시 파싱하고, 구조화 반환 스키마와 단계별 barrier를 사용한다.

tt-focus-group

캐스트 생성 → 각 페르소나의 THINK/TALK/DONE 턴 → 발화 근거 구조화 추출. 사용자·제품 반응의 탐색에 쓰되 실제 조사로 주장하지 않는다.

tt-writing-room

브리프 → 캐스트 → 씬 플랜 → 초안 → 독자/편집 병렬 검증 → 수정. 팀 런에서 발견한 라이팅룸 순서를 반복 가능한 파이프라인으로 만든다.

공통 계약

에이전트가 구조화 값을 반환하고 산출물을 파일로 남긴다. 런 결과와 실행 분석은 .claude/workflows/runs에 분리해 저장한다.

OBSERVED WORKFLOW RUN

동네 빵집 구독제 모의 포커스 그룹

2026-08-02-focus-group-subscription의 journal 및 커밋 산출물에 기록된 실행이다.

01

Cast

persona-architect 1개가 생활 패턴과 경제 판단이 다른 시뮬레이션 참가자 3명을 구성했다.

02

Simulate

3명 × 3단계로 tiny-person-actor 9개가 THINK → TALK → DONE 턴을 수행했다.

03

Extract

추출 에이전트 1개가 참가자별 입장과 근거, 합의·이견을 트레이스에서 구조화했다.

11

에이전트 성공

오류 0, 스킵 0, 빈 반환 0. 실행 시간 9분 10초, 사람 개입 0회로 기록됐다.

161K

토큰 비용

총 161,542 토큰. 누적 트레이스 전체를 매 턴 전달해 후반 턴 비용이 선형으로 증가했다.

3

모의 입장

찬성 1, 조건부 1, 반대 1. 이것은 제품 아이디어를 비판할 관점을 찾은 것이지 실제 수요를 측정한 것이 아니다.

FAILURE FOUND AFTER SUCCESS

11개 에이전트가 성공했지만, 호출 인자는 절반쯤 무시됐다

증상: 1단계 자극과 월드 헤더에 stimulus 문장이 아니라 호출 args JSON 전체가 들어갔다.

원인: 런타임이 객체 대신 JSON 문자열을 넘겼고, 기존 정규화가 그 문자열 전체를 stimulus로 취급했다.

왜 결과가 나왔나: LLM 배우와 추출기가 오염된 문자열 안에서 의도한 질문과 필드를 다시 찾아 의미적으로 복구했다.

조치: tt-focus-group.js와 tt-writing-room.js에 JSON 문자열 파싱 방어가 추가됐다.

교훈: 결과의 자연스러움은 파이프라인 정확성의 증거가 아니다. 입력 원문과 중간 트레이스가 필요하다.

OPERATING DECISION

학생이 자기 프로젝트에서 선택하는 기준

팀을 먼저 쓸 때

문제 정의가 모호하거나, 역할 간 충돌이 품질을 높이거나, 중간 결과에 이의를 제기해야 할 때.

워크플로로 옮길 때

각 단계의 입력·출력 스키마, 중단 조건, 재시도 규칙, 증거 파일이 이미 검증됐을 때.

자동화를 멈출 때

인간 데이터, 법적 판단, 실제 돈, 안전처럼 시뮬레이션만으로 결론내릴 수 없는 경계에 도달했을 때.

SIMULATION BOUNDARY

결과를 현실로 과장하지 않는다

한지우·오미숙·강병철은 전부 생성된 페르소나이며 실제 응답자가 아니다.

합의된 구독 조건은 아이디어 후보이지 사업성, 가격 수용도, 시장 규모의 근거가 아니다.

현실 판단으로 올리려면 실제 고객 인터뷰나 설문을 같은 질문 구조로 수행하고 시뮬레이션과 차이를 비교해야 한다.

이번 런에서 관찰된 사실은 에이전트 실행 지표, 파일 산출, 토큰 증가, 입력 문자열화 결함이다.
