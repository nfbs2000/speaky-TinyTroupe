CLAUDE WORKFLOW ARTIFACT

코드가 지휘한 TinyTroupe workflow와 실행 기록

이 페이지는 .claude/workflows 아래의 workflow 스크립트와 .claude/workflows/runs 실행 문서를 그대로 읽어 보여준다. 팀 런은 사람이 리드하며 판단을 되묻고, 워크플로 런은 코드가 정한 순서대로 반복 실행한다.

WORKFLOW

무엇이 추가됐나

tt-focus-group와 tt-writing-room는 args가 JSON 문자열로 들어오는 경우를 파싱하도록 보강됐다. 앞으로 workflow가 늘어나도 이 페이지는 .claude/workflows 트리를 읽어 목록을 갱신한다.

LATEST RUN

focus-group-subscription

최신 워크플로 런은 동네 빵집 구독제 포커스 그룹이다. 캐스트 1회, 페르소나 턴 9회, 추출 1회로 총 11개 에이전트 호출이 성공했고, 구독 찬성 1명, 조건부 1명, 반대 1명으로 정리됐다.

OBSERVED BUG

args 문자열화 결함

이 런은 결과만 보면 성공이지만, 과정 문서에서 args JSON 전체가 stimulus에 들어간 결함을 발견했다. LLM 페르소나가 의미적으로 복구했기 때문에 결함이 가려졌고, 그 교훈이 workflow 코드 수정으로 되먹임됐다.
