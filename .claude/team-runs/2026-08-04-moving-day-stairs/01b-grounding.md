## 1. 근거 필요 항목 vs 허구 허용

**허구여도 되는 것** — 인물 3인의 이름·나이·외모·사연, 아파트 이름과 계단참의 물성,
이사업체 상호와 인부 수, 짐의 종류, 아래층 주민의 사정, 대화·말투·갈등 전개·결말, 날씨.
> 단 짐의 **무게·치수를 수치로 못박는 순간** 근거 대상으로 넘어간다.
> 이사업체 상호는 실존 브랜드와 겹치지 않는 명백한 가공명으로 (실존 주체 오인 방지).

**브리프가 확정한 설정** (5층/이삿날 오전/엘리베이터 정지/3인/40분/계단참) — 근거 불필요,
다툼 불가. **단 이것은 "설정 확정"이지 "근거 있음"이 아니다.** 분류표에 올리지 않는다.

**상식·관찰 수준** — "엘리베이터가 서면 계단으로 나른다" 류. 검증 가능한 특정 값을
주장하지 않으므로 제외. 과잉 표시는 규율을 무디게 만든다.

**근거 필요** — 검증 가능한 구체 주장: 수치 / 기한 / 의무 주체 / 법령·규약 내용 / 관행의 보편성.

## 2. 3분류표

> **근거 있음 0건 · 근거 없음 0건 · 확인 불가 19건.**
> "근거 없음"이 0인 이유: 그 분류는 "소스를 찾았으나 항목이 없음"이다. 이 저장소에는
> 애초에 주택·이사 소스가 존재하지 않으므로 전부 "등록 소스 범위 밖" = 확인 불가다.
> 세 칸에 억지로 배분하지 않았다.

**돈 층위** (반장의 근거)
| # | 항목 |
|---|---|
| 1 | 계단 운반 추가 요금 관행의 존재 |
| 2 | 층수별 할증 방식 (정액/구간) |
| 3 | 구체 금액 — **원고에서 가장 위험한 항목** |
| 4 | 엘리베이터 사용 불가 시 추가금 청구의 계약상 근거 |
| 5 | 현장 견적 재산정·추가 청구 가능 여부 (표준약관) |
| 6 | 사다리차 사용료 시세 |
| 7 | 추가금 부담 주체 |

**시간 층위**
| # | 항목 |
|---|---|
| 8 | 5층 계단 운반 소요 시간 |
| 9 | 성인 2인 계단 운반 무게 한계 |
| 10 | 대형 가구의 계단 폭·꺾임 통과 여부 |
| 11 | 사다리차의 5층 도달 가능 여부 |
| 12 | 사다리차 설치 조건 (주차·전선·개구부) |
| 13 | 사다리차 호출 후 도착 시간 |

**생활 층위**
| # | 항목 |
|---|---|
| 14 | 승강기 정기 점검 주기와 법적 의무 주체 |
| 15 | 고장 시 관리주체의 신고·수리 의무와 시한 |
| 16 | 관리규약상 이사 신고 / 승강기 사용료 조항 |
| 17 | 이사 소음의 층간소음 규정 적용 여부·시간대 제한 |
| 18 | 계단·복도 적치물 통행·피난 규정 |
| 19 | 사다리차 도로 점용·주차 허가 필요 여부 |

전 항목 사유 동일: **저장소 밖, 웹 모드 꺼짐.**
원고 내 위치 열은 비어 있다 — 초안 이전이므로. **초안 후 2차 대조 필요.**


## 4. 작가 지침

**핵심 원리 — POV 제약이 곧 근거 규율이다.** 외부 초점 서술자는 관행도 법령도 알 수 없다.
확인 불가를 인물의 입으로 내리는 것은 억지 손실이 아니라 **브리프가 이미 요구한 것**이다.

**규칙 1 — 서술문 금지 어미**: `~해야 한다 / ~가 규정이다 / 법적으로 ~다 / 원래 ~다 /
관행상 ~다 / ~하게 되어 있다 / 보통 ~다 / 규약에 따르면 ~다`.
같은 표현이 **큰따옴표 안**이면 허용 — 인물의 주장이지 텍스트의 주장이 아니다.

**규칙 2 — 수치는 화자에게 붙여서만**
```
금지:  5층이라 층당 오만 원씩 추가 요금이 붙었다.
허용:  "오층이면 층당 오만 원 더 받습니다." 반장이 손가락을 폈다.
```
전언체(`반장은 층당 얼마를 더 받는다고 했다`)도 회색지대 — 서술자가 요약하면 승인처럼
읽힌다. **직접 인용으로만.**

**규칙 3 — 확인 불가 수치는 반드시 다투게 한다**
```
"오층이면 층당 오만 원 더 받습니다."
"어제 통화할 땐 그런 말 없었잖아요."
"엘리베이터 선 건 계산에 없었죠."
```
세 가지가 동시 충족 — (a) 금액이 확정되지 않는다 (b) "셋 다 정당한 이유" (c) 열린 결말.
**논쟁 중인 수치는 검증 부채가 없다.**

**규칙 4 — 수치 예산 최대 2~3개**: 금액 1 / 시간 또는 무게 1 / 규정 언급 1. 나머지는
비수치 표현으로 — "층당 얼마씩", "한참", "그 무게".

**규칙 5 — 조항 번호를 대지 않는다**
```
금지:  "관리규약 몇 조에 이사 소음은 아홉 시부터라고 나와 있어요."
허용:  "관리실에 물어봤어요. 이 시간엔 안 된다던데요."
```
두 번째는 **주민이 그렇게 들었다는 사실**만 확정한다. 이중 완충.

**규칙 6 — 사다리차는 오지 않게 설계하라.** 무대에 올리는 순간 11·12·13번이 전부 서술로
확정된다. 대사 안에만 두고, 부를지 말지 다투다 결론이 안 나면 세 항목이 통째로 사라진다.
열린 결말과도 맞는다.

**규칙 7 — 관리사무소는 무대 밖에.** 카메라가 계단참을 벗어나지 않으므로 **통화의 이쪽 편만**
들리게 한다. 상대 답변이 텍스트에 없으면 의무 내용도 텍스트에 없다.

**규칙 8 — 승강기는 "정기 점검"까지만.** 일반명사는 안전. `○개월마다`, `법정 점검일`은 금지.

**규칙 9 — 가구는 이름까지, 치수는 금지.** 물리적 곤란은 **동작으로** — 모서리에 걸려
되돌리는 장면은 치수를 주장하지 않고 통과 불가를 보여준다.
