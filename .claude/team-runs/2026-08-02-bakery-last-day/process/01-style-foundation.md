# 과정 기록 01 — 문체 기조 (narrative-synthesist → 리드 승인)

> 이 파일은 확정 초안(03-draft.md) 이전의 중간 산출물이다. 초안이 이 기조에서
> 어떻게 실현/이탈했는지 대조하는 용도.

## 워커가 제안, 리드가 승인한 기조

- **시점**: 3인칭 외부 초점 (누구의 내면에도 안 들어감, 공간 감각은 서술자에게 허용)
  - 근거: 한 명의 내면 서술 = 그 인물이 주인공화 → 목소리 대비 실험이 깨짐
- **시제**: 과거시제 기본, 마지막 단락만 현재시제 전환 옵션
- **문장 호흡**: 평균 30~45자 단문, 장문 3연속 금지, 비유 문단당 1개 이하
- **대사 비중**: 40~50%
- **목소리 식별 5슬롯**: 문장 길이 / 종결 습관 / 어휘 영역 / 질문:진술 비율 / 침묵 방식
  → 리드가 persona-architect에게 전달해 시트의 말투 항목에 반영하도록 지시
- **신파 차단 목록**: 눈물·포옹, 회상 몽타주, 마지막 인사 대사, 추상 명사(세월·추억·정),
  서술자의 감정 형용사, 셔터 클로징 샷
- **분량**: 목표 2,600자 (6비트 배분: 350/400/450/500/550/350 → 이후 6비트 확정에 맞춰
  350/350/450/550/500/400으로 씬 플랜과 정렬)

## 승인된 문체 견본 (~330자, 초안 아님)

> 여섯 시 십 분, 셔터는 허리 높이에서 멈춰 있었다. 그 아래로 밀가루 자루를 든 팔이
> 먼저 나왔다. 자루가 바닥에 닿는 소리가 났다. 셔터는 더 올라가지 않았다.
>
> 오븐은 밤새 꺼져 있었는데도 문을 열자 미지근한 공기가 나왔다. 벽의 온도계는 눈금
> 사이에서 떨렸다. 진열대에는 종이 깔개만 깔려 있었다. 깔개 가장자리가 접힌 채였다.
> 어제 접힌 것인지 그저께 접힌 것인지는 알 수 없었다.
>
> 밖에서 누군가 유리를 두드렸다. 아직 여섯 시 이십 분이었다.
>
> "안 열었어요."
>
> "압니다."
>
> 두드리던 손이 멈췄다. 유리 너머에서 그림자가 옆으로 한 걸음 옮겨 갔다가, 다시
> 제자리로 왔다.

의도: 감정 형용사 0, 비유 0, 대사 지문 0, 미해소 긴장.

## 변화 기록
- 워커의 초기 갈등 구조안("희소 자원 하나를 셋이 동시에 원함")은 **워커 스스로 폐기**
  — 씬 담당의 촉발 자극(적립카드 무효)이 더 낫다고 판단, 리드 승인.
- craft 리스크 선제 식별: 적립카드가 "28년의 상징"으로 격상되면 신파 직행 → 카드는
  끝까지 구체물·숫자 층위(도장 개수, 남은 칸)로만 다루고 의미 설명 대사 금지.

## 캐스트 선독 후 확정 (리드 승인)
- **대사 배분**: 총 ~1,200자(46%) = 윤경아 540 / 차민규 420 / 서동만 240 (대사 15개 ×
  평균 16자 — "하루 발화 스무 문장"의 2시간 환산). 서동만의 적은 대사 자체가 성격 묘사.
- **서동만 질문 예산 = 1회** ("봉지 드려요?"). 윤경아의 꼬리표("그렇죠?")는 질문으로
  세지 않음.
- **핵심 기교 문제 발견·해결**: 3인칭 외부 초점에서는 "그는 기억하고 있었다"를 쓸 수
  없어 "독자만 아는 구조"의 전달 통로가 지문에 없음 → **부인 가능한 신체 동작**으로
  해결: ① "창가에 테이블 두 개 있었잖아요"에 서동만은 무응답(축5), 손이 멈췄다 다시
  움직임 — 지문은 멈춤의 길이만 적고 이유를 안 적음 ② 결말부에 설명 없이 무언가를
  더 얹어줌, 차민규가 물으면 물건·공정으로 회피(회피가 곧 답) — 윤경아는 확신하지
  못한 채 나감. 마지막 한 판("예약이요")과는 별개 물건 사용.
- **촉발 배치**: 적립카드 무효 = B3 촉발 (윤경아의 숫자·행정어 축과 "우유값을 갚고
  싶다" 동기 양쪽에 걸림), 차민규 훅 3개 = B4 확산용 증폭기.
  → **이력**: 씬 확정 과정에서 카드가 한 번 폐기됐다가(팥 단독 촉발) 오케스트레이터의
  자기 정정으로 **계단 병치로 복원** (02-scene-plan.md 개정 1: 비트 2 팥=명분 상실 →
  비트 3 카드=수단 상실). 카드 신파 방어(숫자 층위 유지, 상징 격상 금지)는 유효하며
  **우유에도 동일 적용**.
