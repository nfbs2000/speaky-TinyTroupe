# 과정 기록 03 — 시뮬레이션 독자 로스터 (audience-reaction-analyst, 초안 도착 전 사전 고정)

> ⚠️ SIMULATED — 아래 3인은 전부 허구의 시뮬레이션 페르소나다. 실제 독자·설문
> 표본이 아니며 반응은 상상적 탐색으로 통계적 타당성이 없다.
> 필드를 초안 도착 **전에** 고정한 이유: 초안을 본 뒤 필드를 만들면 결과가 초안에
> 끌려가기 때문 (워커의 설계 판단, 리드 승인).

## 설계 원칙
브리프의 위험 지점 3개에 독자 1명씩 배치:
"담백·절제→밋밋함" / "사소한 갈등+열린 결말→싱거움" / "목소리 구별 실험 검증".

## 로스터 [SIMULATED]
1. **김세연 (28, 서울, 마케팅 실무자)** — 지하철 모바일 독서, 웹소설 위주, 첫 세
   문단에서 이탈 판단. 여백을 "설명 부족"으로 받아들이는 경향. → 밋밋함·열린 결말
   좌절감 검출 담당.
2. **정만호 (57, 대전, 고교 국어교사)** — 문예지 구독, 절제 문체 선호, 신파 즉각
   거부. 생활 디테일이 있어야 인물을 믿음. → 신파 침범·문장 밀도·디테일 진위 검출.
3. **배도윤 (41, 부산, 프리랜스 디자이너/독서모임 운영)** — 구조 분석형, 동기-행동
   불일치에 민감, "열려 있음"과 "안 쓰다 만 것" 구분. → 목소리 구별 검증 담당
   (발화 이름 가리고 구분 테스트).

## 사전 고정된 추출 스키마
- 목표: 어느 지점에서 반응했고, 브리프 3제약(담백/사소한 갈등/구별되는 목소리)이
  이 독자에게 성립했는가
- 필드: resonated(본문 인용 필수) / confused / emotional_response(강도 low·mid·high) /
  voice_distinguishable(yes·partial·no+근거) / tone_verdict(담백·밋밋·신파 택1) /
  finish_intent(yes·no+이유) / preferred_ending(열린 결말 유지·더 닫힌 결말+근거)
- 집계: tally + 반복 주제 + 이견 지점. 근거 없는 필드는 null.

## 리드 결정
- 전달은 파일 경로로 (01-cast.md, 03-draft.md). voice_distinguishable은 시트 대비 판정.
- 독자 이름이 작중 인물과 충돌하면 리드가 대조 후 통지 → 분석가 쪽 이름 변경.
  → **대조 결과 충돌 없음** (서동만/윤경아/차민규 vs 김세연/정만호/배도윤). 로스터 유지.
- 분석가가 받는 것은 신시시스트의 1차 초안임을 명시.

## 추가 (캐스트 선독 후 확정된 판정 프로토콜)
- **블라인드 테스트 (배도윤 담당)**: 대사에서 화자 표지를 가리고 시트 마커(문장 절단·
  짧은 -요 / 접속사 연쇄·꼬리 질문 / -거든요·외래어·직설 질문)만으로 화자 복원.
  복원율 8할↑ yes, 5~8할 partial, 5할↓ no. **감정 회피 경로 3종(물건·공정 / 숫자·절차 /
  사과 후 화제 추가)의 분화 여부를 별도 집계** — 서동만·윤경아가 뭉개지면 시트가 좋아도
  초안 실패로 보고.
- **위험 3건 사전 식별**: ① 우유 기억이 명시되면 "독자만 아는 구조" 붕괴 → 신파 판정
  가능성 (정만호) ② 차민규 목적 발설 = 악역화·작위 판정 (배도윤) ③ 전원 감정 비진술
  설계 → "아무 일도 안 일어난 글" 위험 — 결함인지 감수할 비용인지 의견 첨부, 판단은
  리드 몫 (김세연)
