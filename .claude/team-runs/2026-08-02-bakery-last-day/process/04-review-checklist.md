# 과정 기록 04 — 검토 체크리스트 (consistency-editor, 초안 도착 전 사전 고정)

> 편집 노트(04b-edit-notes.md) 이전의 중간 산출물. TinyTroupe 소스에서 검토 규율을
> 직접 도출했다는 점이 이 런의 특징.

## 소스에서 도출한 규율 (`tinytroupe/agent/action_generator.py`, `validation/propositions.py`)
- 세 검사는 **서로 배타적** 근거를 쓴다:
  - 페르소나 일관성: 페르소나 명세만 (플롯상의 변호 불인정)
  - 자기 일관성: 작품 내 관측된 서술만 (시트 근거 불인정)
  - 유창성: 문장 자체만
- `hard_action_persona_adherence` 준용: 페르소나 차원은 결함 1건당 경중 무관 감점의
  가혹한 변형 — 이번 브리프의 목적(말투·동기 식별 가능)이 여기 걸려 있으므로.
- `action_suitability`는 상류 기본 OFF → 브리프 하드 제약(분량·어조·열린 결말)은
  핵심 3차원과 **분리된 D항목**으로 보고, 3차원 점수에 섞지 않음.

## 체크리스트 요약
- **A 페르소나 일관성**: 특성 위배 / 말투 / 신념 충돌 / 행동 패턴 / 지식 누출.
  핵심 테스트: 화자 태그 지우고 세 인물 대사가 구별되는가 (실패 = must_fix)
- **B 자기 일관성**: 타임라인 / 사물·공간 연속성(재고 수량, 셔터, 소품) / 정보 상태 /
  물리 상태 / 관계 이력 / 태도 궤적(근거 없는 감정 급전환 = 신파 위험 겸 실패)
- **C 유창성**: 모티프 남용 / 상투구·번역투 / 대사의 구어 발화 가능성 / 리듬 /
  문법 / 인접 비트 기능 중복(`max_action_similarity` 본뜸)
- **D 브리프 적합성** (분리 보고): 분량(공백 포함 기준 명시) / 신파 신호 / 갈등 규모 /
  열린 결말 / 고유명 / 동기 식별

## 형식·정합성 규칙 (리드 승인)
- 노트: `[차원-항목] 위치(단락 번호+인용) | 문제 | 제안 수정 | must_fix: yes|no`
- must_fix 한정: 시트 모순 / 작품 내 사실 충돌 / 브리프 하드 제약 위반 / 문법 오류
- 점수: 차원별 1-10, 통과선 8 (상류 quality_threshold=7 / MAX_SCORE=9의 10점 환산)
- **정합성 규칙**: 8점 미만 차원에는 must_fix 노트 최소 1건 필수 (점수만 낮고 고칠 곳
  못 짚는 상황 방지)

## 캐스트 선독 후 추가 결정 (리드 승인)
1. **A차원은 인물별 채점, 차원 점수 = 최솟값** — 약한 고리가 평균에 가려지면 안 됨
   (브리프: "인물 각자의" 말투·동기 식별). 결함당 -20%이므로 인물당 명백한 위반
   2건 = 그 인물 탈락(6점). 1차 초안 6점대는 척도의 정상 작동.
2. **"명시적 봉합 금지" 위반은 A차원 단일 계상** — 우유 기억 화해 전개는 신파(D)이자
   시트 금기 위반(A)이지만 배타 귀속 규칙에 따라 A에만.
3. **서술자 층위 A-N 신설** — 감정 직접 서술("그는 서운했다"), 내부 사정 노출(불면,
   딸 미통보 암시)은 대사가 아니라 지문에서 터짐. 발견 즉시 must_fix.
4. **분량 기준**: 공백 포함/제외 둘 다 보고, must_fix는 관대한 쪽. 통과 기준 명기.
5. 시트 산술 검증 완료(개업 연도·나이·딸 연령 정합) → 초안이 수치와 어긋나면 초안 오류.
6. D5(고유명): 은성제과·하월동은 승인된 가상명 — 초안이 새로 도입하는 이름만 검사.

## 사전 경고 (신시시스트에게 전달됨)
**남은 빵의 수량 회계**: 세 인물의 동기가 하나의 자원(남은 빵)에 수렴 — 차민규 통째
구매 시도 / 서동만 마지막 한 판 사수 / 윤경아 과다 구매. 재고 수량·타임라인이 장면
내내 산술적으로 맞아야 함. B차원 최중점 검사 지점.

## 경계
에디터는 기교만 비평, 사실성(제빵 공정, 상권 실태) 보증 안 함 — 이번 런에 사실 확인
담당 없음, 최종 통합에서 리드가 감안.
