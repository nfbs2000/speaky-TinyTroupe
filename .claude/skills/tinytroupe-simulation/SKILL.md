# TinyTroupe 시뮬레이션 방법론 (Claude 재현)

## 개요
TinyWorld의 실행 모델을 Claude가 재현한다: **자극 주입(broadcast) → 페르소나별 턴 →
반복**. 각 페르소나는 TinyTroupe의 해석 프로토콜(`tinytroupe/agent/prompts/tiny_person.mustache`)
에 따라 연기되고, 모든 진행은 트레이스 문서에 기록된다.

## 페르소나 해석 프로토콜 (핵심 규칙)
페르소나를 연기할 때 — 직접 하든 `tiny-person-actor` 서브에이전트에 위임하든 — 지킨다:

- **시트가 항상 우선한다.** 어시스턴트 본성(공손함, 긍정성)보다 페르소나가 우선.
  무례한 인물이면 진짜로 무례하게. 모르는 걸 아는 척하지 않는다.
- **행동 타입**: THINK(속생각) / TALK(발화, 대상 지정 가능) / REACH_OUT(접근) / DONE(턴 종료).
- **TALK 전에 반드시 THINK.** 받은 자극에 대해서도 반드시 THINK 한다(무시할 때조차).
- **턴 규칙**: 같은 타입의 행동은 같은 대상에게 턴당 1회 — 합쳐서 하나로. 턴은 DONE으로
  끝나고, 다른 페르소나는 DONE 이후에야 그 행동을 지각한다.
- **자극은 받기만 한다.** 받지 않은 자극을 상상하거나 지어내지 않는다.
- **현실성**: 실수, 망각, 감정, 극단적 선택 모두 허용 — 시트와 일관되면. 같은 행동을
  연속 반복하지 않는다. 할 말이 없으면 그냥 DONE(비상 DONE: 억지 행동보다 무행동이 낫다).
- **절대 시뮬레이션임을 발설하지 않는다** — 페르소나의 생각과 말 속에서.

## 월드 루프
1. **월드 정의**: 이름, 참가 페르소나(시트는 [[tinytroupe-personas]]), 상호 인지 여부.
2. **자극 주입**: 진행자 자극을 전원에게 broadcast (예: "각자 겪는 문제를 공유해 주세요").
3. **턴 진행**: 페르소나를 순서대로 돌며 각자 턴(THINK→TALK→…→DONE)을 수행. 이것이
   1스텝. 단계당 2-3스텝이면 충분한 경우가 많다.
4. **단계 반복**: 단계별 자극으로 진행 (공유 → 발산 → 수렴이 포커스 그룹의 기본형).

## 트레이스 기록 (필수)
모든 스텝을 즉시 기록한다. 이 트레이스가 [[tinytroupe-extraction]]과 [[tinytroupe-story]]의 입력이다.

```
[단계 1 / 스텝 1] 진행자 → 전원 (CONVERSATION): "각자 겪는 문제를…"
  Lisa: THINK 「…」 / TALK→전원 "…" / DONE
  Oscar: THINK 「…」 / TALK→Lisa "…" / DONE
```

## 실행 방식 2가지
- **인라인**: 소규모(페르소나 ≤3, 짧은 런)면 한 세션이 순서대로 전원을 연기한다.
- **서브에이전트**: 페르소나별로 `tiny-person-actor` 에이전트에 위임 — 시트 + 지금까지의
  트레이스 + 이번 자극을 주고 이번 턴의 행동만 받는다. 교차 오염이 없어 더 충실하다.
  `.claude/workflows/tt-focus-group.js` 워크플로가 이 방식을 자동화한다.

## 경계
- 산출물은 시뮬레이션 탐색이다. 실제 인간 데이터로 제시하지 않는다 (README
  "Assistants vs. Simulators", RESPONSIBLE_AI_FAQ.md).
- 큐레이션 시트 참고용: `examples/agents/` (Lisa, Oscar, Marcos 등 7종).
