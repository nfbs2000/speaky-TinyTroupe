# TinyTroupe 기억 방법론 (Claude 재현)

## 근거 소스
`agent/memory.py`(TinyMemory, EpisodicMemory, SemanticMemory, MemoryProcessor,
EpisodicConsolidator, ReflectionConsolidator), `agent/mental_faculty.py`(RecallFaculty),
`agent/tiny_person.py`(`consolidate_episode_memories`, `optimize_memory`,
`retrieve_relevant_memories_for_current_context`, `summarize_relevant_memories_via_full_scan`)

## 개요
인물의 일관성은 시트가 아니라 **기억**에서 무너진다. 시트는 고정이지만 기억은 런 내내
자란다. 이 스킬은 기억을 두 종류로 나누고, 길어질 때 압축하고, 필요할 때 꺼내는 절차다.

---

## 1. 두 종류의 기억

| | 에피소드 기억 | 의미 기억 |
|---|---|---|
| 무엇 | **언제 무슨 일이 있었나** — 시간순 사건·자극·행동 | **무엇을 아는가** — 사실·지식·일반화 |
| 구조 | 순서가 있는 목록. 현재 에피소드(진행 중 버퍼) + 커밋된 에피소드 | 주제별로 검색되는 문서 뭉치 |
| 검색 | 최근 N개, 처음 N개, 마지막 N개 | 관련성 검색(주제어로) |
| 잃으면 | 인물이 무슨 일이 있었는지 모른다 | 인물이 아는 것을 모른다 |

**에피소드 커밋**: 한 장면·한 단계가 끝나면 현재 버퍼를 하나의 에피소드로 확정한다.
확정 이후에는 그 에피소드를 통째로 다루며, 내부 세부는 필요할 때만 펼친다.

---

## 2. 통합 (Consolidation)

트레이스가 길어지면 그대로 들고 갈 수 없다. 오래된 에피소드를 압축한다.

- **행동의 근거는 보존한다.** 무엇을 했는지만 남기고 왜 했는지를 버리면, 이후 판정에서
  자기 일관성을 확인할 수 없게 된다.
- **시간 표시를 유지한다.** 통합된 요약에도 언제 일인지 남긴다.
- **이미지·첨부 참조는 제거한다.** 텍스트 요약만 남긴다.
- 통합은 되돌릴 수 없다고 가정하고 진행한다 — 원본 트레이스는 별도 파일로 보존한다.

### 반추 (Reflection)
통합된 기억에서 인물이 **스스로 끌어내는 일반화**를 별도로 기록한다.
```
사건: 손님이 도장 카드를 내밀었고 주인이 거절했다 (3번 에피소드)
반추: "나는 예외를 만들지 않는 사람이구나" ← 이것이 이후 행동의 근거가 된다
```
반추는 의미 기억에 들어간다. 사건은 잊혀도 반추는 남는다.

## 3. 회상 규약

상황에 따라 다른 방법을 쓴다. 아무거나 쓰면 맥락이 오염된다.

| 방법 | 언제 | 주의 |
|---|---|---|
| **최근 회상** | 직전 흐름을 이어야 할 때 | 가장 싸다. 기본값 |
| **관련성 회상** | 특정 주제에 대해 아는 것을 꺼낼 때 | 상위 몇 개만(기본 7~20). 많이 꺼내면 흐려진다 |
| **전체 스캔 요약** | 긴 런 전체에서 한 주제를 훑어야 할 때 | 비싸다. 최종 통합·검증에만 |

**꺼내지 않은 것은 인물이 모르는 것으로 취급한다.** 회상하지 않은 사실을 인물의 발화에
슬쩍 반영하지 않는다 — 이것이 기억 관리의 존재 이유다.

## 4. 설정 원장 (글쓰기 적용)

픽션에서 기억 모델의 실제 쓰임은 **설정 원장**이다. 세 층으로 관리한다.

```
[산술 층]  세는 것 — 재고, 현금, 남은 시간, 횟수
           예: 재고 12 = 담기 6 + 구매 3 + 정리 3 / 현금 12,000 − 8,000 − 1,500 = 2,500
[사물 층]  등장한 물건의 위치와 상태 — 한 번 나온 물건은 사라지지 않는다
[기억 층]  인물별로: 아는 것 / 모르는 것 / 잊은 것 / 착각하는 것
```

- **초안 전에 개설한다.** 초안을 쓴 뒤 맞추려 하면 이미 늦다.
- **인물마다 아는 범위가 다르다.** 독자만 아는 것, A만 아는 것, 모두 아는 것을 구분한다.
  비대칭 인지는 픽션의 주요 장치이므로 원장에 명시한다.
- 초안이 나오면 원장과 **한 줄씩 대조**한다. 불일치는 위치와 함께 보고한다.
- 원장 관리자는 원고를 고치지 않는다. 불일치를 보고하고 수정은 작가가 한다.

## 산출 형식

```
## 설정 원장 v1 (개설: 비트 플랜 확정 직후)
### 산술
| 항목 | 초기값 | 변동 | 최종 | 근거 비트 |
### 사물
| 물건 | 등장 비트 | 위치 변화 | 최종 상태 |
### 인물별 인지
| 사실 | A | B | C | 독자 |
|---|---|---|---|---|
| … | 앎 | 모름 | 착각 | 앎 |

## 대조 결과 (대상: 초안 v2)
| # | 불일치 | 위치 | 원장 값 | 원고 값 |
```

## 경계
- 원장은 **사실 관계의 정합성**을 본다. 문장의 좋고 나쁨은 [[tinytroupe-quality]]의 일이다.
- 통합·반추로 만들어낸 내용을 인물이 실제로 겪은 일처럼 새로 만들어내지 않는다 —
  통합은 있는 것을 줄이는 일이지 없는 것을 채우는 일이 아니다.
- 잠정 표시: 확정 전 판본을 대조한 결과에는 "잠정"을 붙인다.
