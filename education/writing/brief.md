# Writing Brief — TinyTroupe Writing Room 1차 공개 실험

- **Team:** `tinytroupe-writing-room`
- **Lead:** writing-room-showrunner (this Claude session)
- **작성일:** 2026-07-30

## 1. 선택한 글의 형식과 주제

- **형식(Form):** 단편 소설 (short fiction)
- **제목(가제):** 「막차」
- **주제(Subject):** 서로 다른 삶의 자리에 있는 세 승객이 심야 시내버스 막차에서
  우연히 나누게 되는 짧은 대화. 각자의 하루를 짊어진 인물들이 잠깐 스치는 동안
  서로를 조금씩 이해하게 되는 이야기.

## 2. 목적 (Purpose)

이 글은 TinyTroupe의 핵심 아이디어 — *사람을 이해하고 상상력을 확장하기 위해
페르소나를 시뮬레이션한다* (README "Assistants vs. Simulators") — 를 **글쓰기의
분업 구조**로 번역했을 때 나오는 결과물을 보여준다. 구체적으로:

1. **페르소나 탐구:** 뚜렷하게 구별되는 인물들이 각자의 목소리로 살아 움직이는가.
2. **상상력:** 하나의 제약된 공간(버스)과 자극(막차라는 상황)에서 진짜 긴장과
   감정이 피어나는가.
3. **시뮬레이션된 독자 반응:** 다양한 독자가 이 글을 어떻게 받아들일지 탐색한다.
   (단, 이 반응은 *시뮬레이션된 상상*이며 실제 설문·조사가 아님.)

## 3. 대상 독자 (Audience)

- 공개 GitHub Pages에서 이 실험을 처음 접하는 일반 한국어 독자.
- 특별한 배경 지식 없이도 그 자체로 읽는 재미가 있어야 한다.

## 4. 제약 (Constraints)

- 분량: 한국어 기준 약 1,500~2,500단어.
- 언어: 한국어 서사 산문.
- 톤: 따뜻하되 감상적이지 않게. 인물의 결이 서로 분명히 달라야 한다.
- 사실 주장이 아닌 창작물로 읽혀야 한다.

## 5. 근거 경계 (Evidence Boundary)

- 이 팀의 자식 에이전트는 실제 Claude Agent SDK 워커다. 이들이 만들어내는
  **등장인물과 시뮬레이션된 독자는 허구/시뮬레이션**이며, 실제 인물·실제 설문
  참가자로 제시하지 않는다.
- 런타임 ID가 확인되지 않으면 `null`로 남기며, 이름에서 추론하지 않는다.

## 6. 워커별 위임 과제 (Bounded Tasks)

| 워커 | 위임 과제 | 산출물 |
| --- | --- | --- |
| persona-architect | 막차에 탄 3명의 승객 + 기사, 캐릭터 시트 | 페르소나 시트 |
| scene-orchestrator | 버스라는 공간과 막차 상황의 장면/비트 플랜 | 비트 플랜 |
| narrative-synthesist | 시트+비트를 1,500~2,500단어 단편으로 렌더링 | 초고 |
| audience-reaction-analyst | 초고에 대한 시뮬레이션 독자 반응(라벨 명시) | 반응 노트 |
| consistency-editor | 초고의 페르소나 일관성·연속성·문장 점검 | 편집 노트 |

리드는 위 모든 반환물을 읽은 뒤 최종 원고를 직접 통합해 작성한다.
